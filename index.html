      08 · NOTES ON DATA

      분석 기준

      한국 시간과 주차의 기준

      한국 표준시(Asia/Seoul) 기준 월요일 00:00부터 일요일 23:59:59까지. 이 보고서 기준 지난주는 2026년 10월 19–25일이며, 전전주는 10월 12–18일입니다.

      Metricool 연결 이전 데이터가 없으면?

      기록이 반환되지 않은 기간은 미집계로 둡니다. 연결일 이전 날짜가 0.0이라고 응답하더라도 확인 가능한 실측치라고 단정하지 않습니다.

      지표의 의미는 무엇인가요?

      팔로워는 기간 말 관측치, 신규·이탈은 각 날의 발생 건수입니다. 계정 조회는 노출 횟수에 가깝고 도달은 사용자 수 기반 지표입니다. 릴스 평균 시청시간과 3초 초과 시청 비율은 릴스의 관측치일 때만 제공됩니다.

      어떻게 다음 주 데이터를 반영하나요?

      Metricool 분석 데이터를 주간 JSON 형식으로 가져오면 기록을 병합합니다. 같은 주차가 다시 들어오면 그 주차만 갱신하며 다른 주차는 유지합니다. 수정 후 반드시 ‘업데이트된 사이트 HTML 저장’을 눌러 최신 파일을 보관하세요.
